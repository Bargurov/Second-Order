# פיילוט FOMC: רשימת צעדים לליל ההודעה וליום קליטת התוצאות

המסמך מפרט את הפרוטוקול המאושר (`docs/pilot/fomc-pilot-protocol.md`). הפרוטוקול אושר ב-7.11.2026 כפיילוט showcase,
וחותמת ההתחלה היא `2026-12-01T00:00:00+00:00`. השרת צריך לרוץ עם `--enable-market-retrieval`. כל השעות כאן הן **שעון ישראל**, לפי
ההודעה של 9 בדצמבר 2026. בלוח שלמטה מופיעים התאריכים האחרים, ושימו לב במיוחד ל-17.3.2027.

## לפני כל ליל הודעה (פעם אחת, עד הצהריים)

1. השרת רץ עם `--enable-market-retrieval`.
2. בודקים את היומן:
   ```
   python -m second_order pilot-ledger --table
   ```
   השורה של ההודעה צריכה להיות במצב `scheduled`.
3. הכינו מראש טיוטה של ההשערה במסמך נפרד. מקלידים אותה בטופס רק בשלב 9 בלילה.

## יום קליטת התוצאות (שישי, 18.12.2026, מ-23:15, או כל יום מאוחר יותר)

1. בדף Hypotheses, באזור Outcome data, בוחרים את המקרה ומציגים את תוכנית ההורדה.
   - אם כתוב "None yet: … await the Board's release, obtainable from …", מחכים למועד שמופיע שם. התוכנית לא תציע הורדה
     שתחזיר נתונים חסרים.
   - אם כתוב "One: the full release package", ממשיכים.
2. מאשרים הורדה אחת. התוצאה צריכה להיות `saved` עם `accepted`.
3. מייבאים את החבילה כתוצאה של המקרה (outcome import).
4. בודקים את מצב המקרה. צריך להופיע "Ready for an explicit assessment". אם מופיע "a leg will be unavailable", יש יום
   מסחר בלי ערך (ND), והרגל תסומן unavailable. זה נרשם כמות שהוא.
5. מציגים את ההערכה ומאשרים פעם אחת "Evaluate and prepare Dossier". התוצאה לא מוצגת לפני האישור.
6. בודקים ביומן: `pilot-ledger --table`. השורה צריכה להיות `assessed`, עם תווית השנתיים, ותווית עשר השנים לידה.
